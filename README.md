# ÁRBOL by KLIK
## Sistema de Búsquedas y Armado de Árbol Genealógico

**Estado:** BASELINE DOCUMENTAL / EN CONSTRUCCIÓN  
**Naturaleza:** Sistema local-first de búsquedas y armado de árbol genealógico  
**Principios:** SOURCE FIRST · ZERO SYNTHETIC · ZERO AI sobre evidencia histórica

## 1. Propósito

ÁRBOL by KLIK es un sistema de búsquedas y armado de árbol genealógico destinado a investigar,
documentar, relacionar y preservar la historia genealógica de una familia con trazabilidad de evidencias.

El objetivo no consiste únicamente en construir un árbol de nombres.

El sistema deberá permitir reconstruir:

Persona
→ Relaciones familiares
→ Generaciones
→ Lugares
→ Documentos
→ Fotografías
→ Testimonios
→ Acontecimientos
→ Fuentes
→ Evidencia

Cada afirmación genealógica deberá conservar su procedencia y nivel
de verificación.

---

## 2. Principio rector

La evidencia tiene autoridad sobre la inferencia.

El sistema deberá distinguir expresamente entre:

- HECHO DOCUMENTADO
- INFORMACIÓN FAMILIAR
- TESTIMONIO
- HIPÓTESIS
- COINCIDENCIA
- DESCONOCIDO
- DESCARTADO

Una coincidencia de nombres no constituye una identidad.

Una coincidencia de identidad no demuestra automáticamente un parentesco.

Un árbol genealógico publicado por terceros no constituye por sí mismo
evidencia suficiente.

---

## 3. ZERO SYNTHETIC

El sistema no deberá inventar:

- personas;
- nombres;
- fechas;
- lugares;
- matrimonios;
- filiaciones;
- parentescos;
- documentos;
- acontecimientos;
- fotografías;
- identidades.

Cuando un dato sea desconocido deberá permanecer como DESCONOCIDO.

Cuando exista una hipótesis deberá identificarse explícitamente como
HIPÓTESIS.

---

## 4. ZERO AI sobre evidencia histórica

Fotografías, documentos, cartas, actas y demás fuentes originales son
evidencia histórica.

La evidencia original nunca deberá ser sustituida por contenido generado.

Para fotografías históricas se permiten procesos tradicionales de
conservación tales como:

- enfoque;
- claridad;
- contraste;
- niveles;
- corrección cromática;
- reducción de ruido;
- ampliación mediante algoritmos tradicionales.

No se permitirá utilizar generación para reconstruir rostros, cuerpos,
expresiones, objetos o información inexistente.

Principio:

> La tecnología puede mejorar la lectura de la evidencia.
> No puede reescribirla.

---

## 5. Modelo conceptual

El núcleo del proyecto será la PERSONA.

Cada persona podrá relacionarse con:

- padres;
- hijos;
- hermanos;
- parejas;
- matrimonios;
- familias;
- fotografías;
- documentos;
- lugares;
- acontecimientos;
- testimonios;
- fuentes.

Las relaciones deberán conservar evidencia independiente.

---

## 6. Investigación progresiva

La investigación podrá avanzar:

### Verticalmente

Generación actual
→ Padres
→ Abuelos
→ Bisabuelos
→ Tatarabuelos
→ generaciones anteriores

### Horizontalmente

Persona
→ hermanos
→ parejas
→ hijos
→ sobrinos
→ primos
→ ramas relacionadas

Las ramas laterales podrán utilizarse para encontrar evidencia sobre
generaciones anteriores.

---

## 7. Fuentes

El proyecto podrá utilizar fuentes como:

- Registro Civil;
- archivos parroquiales;
- archivos históricos;
- censos y padrones;
- hemerotecas;
- cementerios;
- documentos familiares;
- fotografías;
- escrituras;
- correspondencia;
- testimonios;
- repositorios genealógicos;
- fuentes digitales;
- APIs autorizadas;
- bases documentales públicas.

Los proveedores externos serán FUENTES.

No serán la autoridad maestra del árbol familiar.

---

## 8. Investigación asistida

El sistema podrá utilizar herramientas automáticas para:

- localizar candidatos;
- buscar variantes nominales;
- relacionar fechas;
- comparar localidades;
- detectar posibles coincidencias;
- localizar documentos;
- organizar evidencia.

Una herramienta automática podrá PROPONER.

No podrá CONFIRMAR por sí sola una relación genealógica.

---

## 9. Preservación

Todo documento original deberá conservarse intacto.

Las versiones procesadas deberán almacenarse separadamente.

Conceptualmente:

ORIGINAL
│
├── copia de preservación
├── transcripción
├── versión de consulta
└── versión restaurada ZERO AI

Cuando resulte aplicable podrán utilizarse huellas criptográficas para
verificar la integridad del original.

---

## 10. Baseline familiar inicial

El sistema se inicia sin datos pre-cargados de ninguna familia real. 
Los investigadores podrán dar de alta múltiples casos de estudio independientes. 
Cada caso de estudio partirá de un estado de hipótesis o información de tradición familiar, 
el cual se irá consolidando estrictamente mediante la adición de fuentes y evidencias documentadas.

Cualquier dato utilizado en ejemplos visuales o guías de uso es meramente conceptual 
y no representa una pre-configuración de datos del sistema.

---

## 11. Objetivo

Construir progresivamente un archivo familiar:

TRAZABLE
VERIFICABLE
PRESERVABLE
AUDITABLE
EXTENSIBLE

capaz de explicar no solamente quién fue cada persona, sino:

quiénes fueron sus familiares,
dónde vivieron,
qué documentos dejaron,
qué acontecimientos atravesaron
y qué evidencia permite reconstruir su historia.

---

## 12. Regla final

> Buscar no es demostrar.
> Coincidir no es identificar.
> Identificar no es demostrar parentesco.
> La evidencia manda.
